# Ayanfe's Day

A cinematic, frontend-only birthday experience built with React, TypeScript, Vite, and Framer Motion.

## Run locally

```bash
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```

## Personal media

Place optional files at these paths before sharing the site:

- `public/images/us-together.jpeg`
- `public/media/photo1.jpg`
- `public/media/photo2.jpg`
- `public/media/photo3.jpg`
- `public/media/video1.mp4`
- `public/media/voice-note.mp3`
- `public/media/birthday-video.mp4`
- `public/audio/birthday-song.mp3`

The experience gracefully displays a media placeholder when a personal file is not present.
